CALCOLO DEI CASI DI TEST:

--- 1. SalvataggioPartita(Partita partita) ---
Il dominio di input dipende dallo stato del file fisico sull'hard disk e dalla presenza del nome della partita al suo interno.

CE1_S (Valida): Il file 'archivioPartite' non esiste (deve essere creato).
CE2_S (Valida): Il file 'archivioPartite' esiste.
CE3_S (Valida): Il nome della partita non è presente nel file (logica di Append).
CE4_S (Valida): Il nome della partita è già presente nel file (logica di Sovrascrittura).

Test Case derivati:
- TC_SAVE_01 (copre CE1_S): file non esistente, input "Partita_A". 
  Risultato atteso: creazione del file, esito vero.
- TC_SAVE_02 (copre CE2_S + CE3_S): file esistente, input "Partita_B". 
  Risultato atteso: record accodato alla fine del file, esito vero.
- TC_SAVE_03 (copre CE2_S + CE4_S): file esistente, input "Partita_A" aggiornata. 
  Risultato atteso: riposizionamento puntatore e record sovrascritto, esito vero.
- TC_SAVE_04 (copre CE4_S): nuova partita con nome già presente ma non ancora salvata (caso limite logico). 
  Risultato atteso: record sovrascritto senza creare duplicati, esito vero.

--- 2. RecuperoPartita(char nomeDaCercare[20]) ---
Il dominio di input dipende dall'esistenza e integrità del file, e dalla stringa immessa per la ricerca.

CE1_R (Non Valida): Il file non esiste sul disco.
CE2_R (Non Valida): Il file esiste ma ha dimensione 0 byte.
CE3_R (Valida): Il file esiste e contiene almeno un record.
CE4_R (Valida): Il nome cercato esiste nel file (Limiti: LIM1 in testa, LIM2 nel resto del file).
CE5_R (Non Valida): Il nome cercato non esiste all'interno del file.

Test Case derivati:
- TC_LOAD_01 (copre CE3_R + CE4_R + LIM1): cerca "Partita_A" (prima posizione). 
  Risultato atteso: ciclo interrotto subito, recupero effettuato, esito vero.
- TC_LOAD_02 (copre CE3_R + CE4_R + LIM2): cerca "Partita_B" (seconda posizione). 
  Risultato atteso: ciclo avanza e legge secondo record, esito vero.
- TC_LOAD_03 (copre CE3_R + CE5_R): cerca "Partita_X" (inesistente). 
  Risultato atteso: raggiungimento EOF, esito falso.
- TC_LOAD_04 (copre CE1_R): file mancante, cerca "Partita_A". 
  Risultato atteso: fallimento apertura file in lettura, esito falso.
- TC_LOAD_05 (copre CE2_R): file vuoto, cerca "Partita_A". 
  Risultato atteso: EOF immediato al primo controllo MENTRE, esito falso.
