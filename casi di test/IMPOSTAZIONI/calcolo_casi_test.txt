CALCOLO DEI CASI DI TEST (Tecnica: Classi di Equivalenza)

Abbiamo analizzato alcune delle funzioni principali del file impostazioni.c per determinare le Classi di Equivalenza (CE) valide e non valide, e i valori limite. Da queste CE, abbiamo derivato i relativi Casi di Test (TC).

--- 1. Set_modoPartita(int m) ---
Il parametro 'm' dovrebbe logicamente accettare solo 0 (Persona) o 1 (CPU).
CE1 (Valida): m = 1
CE2 (Valida): m = 0
CE3 (Non Valida): m < 0 oppure m > 1 (Es. m = 5)

Test Case derivati:
- TC1 (copre CE1): input m=1. Risultato atteso: 1
- TC2 (copre CE2): input m=0. Risultato atteso: 0
- TC3 (copre CE3): input m=5. Risultato atteso: 5 (Nota: poiché il codice attuale non fa validazione dell'input, ci aspettiamo che il valore venga accettato così com'è, oppure fallisca se in futuro viene implementata la validazione).

--- 2. Set_nomeGiocatore1(Stringa n1) ---
Il parametro Stringa contiene un array di char 'data[20]'. La funzione usa strncpy copiando al massimo 19 caratteri (sizeof(...) - 1) per lasciare spazio al terminatore.
CE4 (Valida): lunghezza stringa tra 1 e 19 caratteri.
CE5 (Limite): lunghezza stringa = 0 (stringa vuota).
CE6 (Non Valida/Limite): lunghezza stringa >= 20 caratteri.

Test Case derivati:
- TC4 (copre CE4): input "Mario" (5 char). Risultato atteso: "Mario".
- TC5 (copre CE5): input "" (0 char). Risultato atteso: "".
- TC6 (copre CE6): input "12345678901234567890_Extra" (26 char). Risultato atteso: troncamento ai primi 19 caratteri ("1234567890123456789").

--- 3. Set_numeroRound(int r) ---
Il parametro 'r' rappresenta i round della partita (logicamente dovrebbe essere r > 0).
CE7 (Valida): r > 0
CE8 (Non Valida): r <= 0

Test Case derivati:
- TC7 (copre CE7): input r=3. Risultato atteso: 3.
- TC8 (copre CE8): input r=-1. Risultato atteso: -1 (Anche in questo caso verifichiamo la reazione del codice attuale che non ha controlli).

--- 4. cercaBottone(AreaCliccabile b[], int n, int r, int c) ---
Controlla se il click in (r, c) cade nel bottone b[i].
CE9 (Valida): click interno al bottone (r == b[i].r E c compreso tra b[i].c1 e b[i].c2).
CE10 (Non Valida): click esterno al bottone (riga o colonna errata).

Test Case derivati:
- TC9 (copre CE9): Area={10, 5, 15, 99}, click su (10, 10). Risultato atteso: 99.
- TC10 (copre CE10): Area={10, 5, 15, 99}, click su (11, 10). Risultato atteso: 0.
