Funzione stampaSchermataSupporto
INPUT
NomeSchermata, nome del file della schermata da stampare, stringa di caratteri
OUTPUT
LAVORO
Fp, puntatore al file della schermata, file
C, carattere letto dal file, intero
NomeCompleto, percorso completo del file, stringa di caratteri
NomeCompleto = PERCORSO_SUPPORTO + NomeSchermata
Fp = AprireFile(NomeCompleto, lettura)
SE (Fp = NULL)
ALLORA StampareAVideo("Errore caricamento schermata supporto")
ALTRIMENTI
C = LeggereCarattereDaFile(Fp)
MENTRE (C <> EOF)
StampareAVideo(C)
C = LeggereCarattereDaFile(Fp)
FINE
ChiudereFile(Fp)
StampareAVideo(a capo)
FINE
