Funzione stampaSchermataMenu
INPUT
S, nome del file della schermata da stampare, Stringa
OUTPUT
LAVORO
Fp, puntatore al file della schermata, file
C, carattere letto dal file, intero
NomeCompleto, percorso completo del file, stringa di caratteri
NomeCompleto = PERCORSO_MENU + campo data di S
Fp = AprireFile(NomeCompleto, lettura)
SE (Fp = NULL)
ALLORA StampareAVideo("Errore caricamento schermata menu")
ALTRIMENTI
C = LeggereCarattereDaFile(Fp)
MENTRE (C <> EOF)
StampareAVideo(C)
C = LeggereCarattereDaFile(Fp)
FINE
ChiudereFile(Fp)
FINE
